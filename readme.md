Tempo — шашки с AI-тренером
Live: checkers-eta.vercel.app

Что это
Веб-платформа для игры в шашки с тремя режимами: онлайн с другом по ссылке, случайный матч с реальным игроком и партия против ИИ на пяти уровнях сложности. После каждой завершённой партии можно открыть анализ: движок оценивает каждый ваш ход и помечает его как best / good / inaccuracy / mistake / blunder, показывает лучший ход на доске, а Llama 3.3 70B объясняет на человеческом языке — почему ход был сильным или в чём была ошибка.

Для кого
Для тех, кто хочет не просто играть в шашки, а расти как игрок. Существующие платформы дают только доску и противника — ты сыграл, проиграл, не понял почему. Tempo показывает: вот здесь у тебя было двойное взятие, ты его не увидел; вот здесь ты подставил дамку.
Целевая аудитория — взрослые любители 25-45 лет, которые в детстве играли в шашки и хотят вспомнить/прокачаться; родители, играющие с детьми и желающие подтянуть навык; и любые игроки, которым обычные шашечные приложения кажутся скучными после нескольких партий.

Почему это ценно
1. AI Coach с реальными объяснениями. Большинство шашечных приложений если и предлагают «анализ», то ограничиваются шаблонной фразой «engine prefers X». Tempo даёт связное объяснение от языковой модели: что было упущено, какая тактическая идея за лучшим ходом, чем плох выбранный ход. Это превращает каждую партию в урок.
2. Полноценный движок, не игрушка. Под капотом — minimax с alpha-beta pruning, эвристика учитывает материал, продвижение, контроль центра и защиту последнего ряда. Гроссмейстерский уровень (depth 5) даёт серьёзный вызов даже опытным игрокам.
3. Дешёвый порог входа. Бесплатный план даёт всё функционально: мультиплеер, ИИ всех уровней, базовый анализ с оценкой ходов и подсветкой лучшего хода. Платный план ($7/мес) снимает ограничение на 1 AI-объяснение в день — для тех, кто хочет учиться системно.
4. Готовая бизнес-модель. Не «когда-нибудь добавлю Stripe», а работающая воронка: Gumroad → webhook → база → автоматическое снятие лимитов. С момента покупки до Pro-доступа — секунды.

Технологии
React 18 + TypeScript + Vite + Tailwind + Framer Motion на фронтенде. Supabase для авторизации, базы, realtime-синхронизации мультиплеера и Edge Functions. Groq API для Llama 3.3 70B. Gumroad для платежей. Деплой на Vercel.
